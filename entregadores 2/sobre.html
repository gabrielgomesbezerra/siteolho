Arquitetura e Hardware

Como a eletrônica, a mecânica e o navegador trabalham juntos.

⚙️ Especificações

Como o Sistema Funciona

Este projeto combina mecânica articulada, microcontrolador Arduino e tecnologias modernas de navegador (Web Serial API e WebRTC/PeerJS) para mover um olho animatrônico em dois eixos e acionar sua pálpebra em tempo real.

Componentes Principais

🧠 Microcontrolador

Placa Arduino (Uno, Nano ou Mega) configurada a 9600 bps para receber coordenadas no formato X,Y e comandos de piscar (P).

⚙️ Atuadores

3 Micro Servos (SG90 ou MG90S) responsáveis pelos movimentos horizontais (Pino 9), pálpebra (Pino 10) e verticais (Pino 11).

📱 Controle Multi-Dispositivo

Comunicação direta via cabo USB no computador e pareamento remoto instantâneo para controle via toque na tela do celular.
